# Security policy

## Supported versions

Security fixes go into the latest minor release of the current major
version (for example 1.2.x once 1.2.0 is out), and into `main`.

## Reporting a vulnerability

Please do not open a public issue. Report it privately through
[GitHub's security advisories](https://github.com/davy-tw/tailnet-gateway/security/advisories/new)
for this repository, with the affected version and steps to reproduce.

Vulnerabilities in Tailscale itself (tailscaled, the `tailscale/tailscale`
image) should go to [Tailscale](https://tailscale.com/security).
